## Hi there :)
### this is a very eazy install

1. copy my dotfiles
```sh
cd
git clone git@github.com:KoenBrouwer1/dotfiles.git
cd dotfiles
```

2. then chmod the install and setup script
```sh
chmod +x install.sh
chmod +x setup.sh
```

3. run the install script
```sh
./install.sh
```

4. run the setup script
```sh
./setup.sh
```

and you should be done
